# math-game

Jeu de calcul mental pour Zozo et Gabi : une partie de cinq minutes pour
enchaîner additions et soustractions dont les réponses vont de 0 à 20.

Ouvrir `index.html` dans un navigateur pour jouer. Les meilleurs scores et les
exercices ratés sont enregistrés séparément pour chaque joueuse dans le stockage
local du navigateur.

Pour publier le jeu sur Firebase Hosting, exécuter `firebase deploy --only hosting`.
